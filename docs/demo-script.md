# RampUp walkthrough

1. Sign in with the privately shared learner account. Open the inventory task.
2. Read its milestones and protected-path policy. Ask about the code or share an attempt. Cited answers can open pinned source excerpts.
3. Use **Ask my mentor** for a manual handoff. Coaching pauses; the learner may still send clarifications.
4. In a separate browser tab, sign in as the mentor. Open **Review queue**, inspect the case and conversation, and edit **Your response**. A new learner message requires reviewing the refreshed context before deciding.
5. Send guidance. In the learner tab, confirm the mentor response arrives and coaching resumes. Drafts survive polling; a failed response can retry the original request.
6. Request completion review. The mentor opens **Completion reviews**, checks the evidence and leaves a review note. **Return for changes** resumes work. **Confirm completion** requires a final confirmation and makes the learner workspace read-only.

Use an isolated test database for a repeatable final-completion demonstration so the shared demo task remains usable. No learner code is executed. Do not display credentials or internal undelivered proposals to learners.
